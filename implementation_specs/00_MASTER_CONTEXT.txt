NAVIFREIGHT — MASTER IMPLEMENTATION CONTEXT

Purpose
Build a credible Sept 10 hackathon MVP for:
“Development of an Intelligent Freight Forecasting Model for Optimized Vessel Chartering and Bulk Cargo Procurement from overseas to East Coast of India”

Core product thesis
NaviFreight does not merely show the market. It interprets the market and tells the user what decision to make.

Decision hierarchy:
1. Decision
2. Explanation
3. Evidence

Primary user questions
- When should I buy the commodity?
- Which vessel should I use?
- What freight rate should I expect?
- Should I charter now or wait?
- Why?

Primary workflow
User selects:
- Commodity
- Origin
- Destination
- Intended cargo volume

System returns:
- BUY / WAIT / MONITOR commodity procurement signal
- Expected freight $/t
- Recommended vessel
- CHARTER NOW / WAIT / MONITOR FREIGHT
- Overall strategy
- Why / evidence
- Landed cost
- Vessel comparison
- Historical freight context
